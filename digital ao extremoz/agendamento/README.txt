# Sublime Saúde - Atendimento Simplificado

Este projeto foi recriado a partir do código enviado.

A página original utiliza Tailwind CSS, várias configurações de
cores, espaçamentos, fontes e classes utilitárias.

Nesta versão tudo foi reconstruído usando somente:

- HTML
- CSS
- JavaScript

Arquivos:

- index.html
- style.css
- script.js

O objetivo é que o código seja fácil de ler para quem está
aprendendo a fazer sites.

Abra o index.html no navegador para ver a página.

Os botões usam alert() apenas como exemplo. Depois eles podem
ser substituídos por páginas, formulários ou outras funções.
