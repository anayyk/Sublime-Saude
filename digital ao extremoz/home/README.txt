# Sublime Saúde - Home simplificada

Esta versão foi criada a partir do segundo código enviado.

O código original usa Tailwind CSS, configuração de cores,
fontes externas e muitas classes. A versão nova usa somente:

- HTML
- CSS
- JavaScript

A ideia visual principal foi mantida:

- Cabeçalho com menu
- Nome Sublime Saúde
- Título "Saúde de Qualidade para Todos"
- Botão de atendimento presencial
- Botão de atendimento online
- Área visual da clínica
- Rodapé

Os botões possuem funções JavaScript simples com alert().
Isso facilita o estudo antes de criar páginas e formulários reais.
